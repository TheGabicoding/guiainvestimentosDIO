# guiainvestimentosDIO
>CONTEXTO E OBJETIVOS
Este repositório foi criado no bootcamp da DIO em parceria com a Bradesco com o objetivo de usar a ferramenta notebooklm e explorar seu potencial.
Escolhi o assunto de investimentos pois tive e tenho interesse em métodos de aumentar o meu patrimônio e organizar melhor o dinheiro, que é um conteúdo que é fundamental para se viver bem. 
Era um conteúdo que eu já tinha interesse e o projeto surgiu como uma maneira de aprofundar meus conhecimentos em dois assuntos de interesse, IA e economia, que convergem aqui nesse repositório.
